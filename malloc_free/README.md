# malloc_free

Tasks on dynamic memory allocation in C, using `malloc` and `free`. Each task is one file, and all prototypes are in `main.h`.

## Files

| File | Description |
|---|---|
| `main.h` | Prototypes of all the functions of this project |
| `0-create_array.c` | Creates an array of chars and initializes it with a specific char |
| `1-strdup.c` | Returns a pointer to a newly allocated copy of a string |
| `2-str_concat.c` | Concatenates two strings into newly allocated memory |

## Compilation

Compiled on Ubuntu 20.04 LTS with:

gcc -Wall -Werror -Wextra -pedantic -std=gnu89 *.c -o program
