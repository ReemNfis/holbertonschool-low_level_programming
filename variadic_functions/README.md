# C - Variadic functions

| File                   | Description                                                     |
| ---------------------- | --------------------------------------------------------------- |
| `variadic_functions.h` | Header file with all prototypes                                 |
| `0-sum_them_all.c`     | Returns the sum of all its parameters                           |
| `1-print_numbers.c`    | Prints numbers separated by a separator, followed by a new line |
| `2-print_strings.c`    | Prints strings separated by a separator, followed by a new line |
