# C - Structures, typedef

Learning how to define and use structures and `typedef` in C.

## Files

| File | Description |
| --- | --- |
| `dog.h` | Header file: defines `struct dog` (name, age, owner), its alias `dog_t`, and the prototypes |
| `1-init_dog.c` | Function that initializes a variable of type `struct dog` |
| `2-print_dog.c` | Function that prints a `struct dog` (prints `(nil)` for NULL elements) |
| `4-new_dog.c` | Function that creates a new dog, storing copies of `name` and `owner` |
